# 替换小程序二维码

README 里的体验二维码目前是占位图（`docs/qr-placeholder.png`）。小程序上线后按以下步骤替换。

## 获取真实二维码

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 进入「荧烛微光」小程序
2. 「设置 → 基本设置」可看到小程序码
3. 或在「管理 → 版本管理」对已发布版本点「生成二维码」

推荐用**小程序码**（圆码）而非普通二维码，视觉上更精致、更契合本项目调性。

## 替换占位图

把下载的二维码图片命名为 `qr.png` 放进 `docs/` 目录，然后把 `README.md` 里的：

```markdown
<img src="docs/qr-placeholder.png" alt="小程序二维码" width="220">
```

改成：

```markdown
<img src="docs/qr.png" alt="荧烛微光小程序码" width="220">
```

## 同时更新体验版二维码（可选）

如果还在审核中，想先让朋友体验，可以用**体验版二维码**：

1. 微信开发者工具 → 上传代码 → 生成体验版
2. 「管理 → 版本管理 → 体验版」生成二维码
3. 体验版需要把体验者微信号加入白名单（「管理 → 体验者权限」）

体验版二维码也可以放进 README，标注「体验版（需白名单）」。

## 二维码规格建议

- 尺寸：至少 430×430（微信生成的默认尺寸就够）
- 格式：PNG（不要 JPG，二维码边缘会糊）
- 周围留白：至少留 4 个模块的「静区」，否则部分扫码器识别困难
