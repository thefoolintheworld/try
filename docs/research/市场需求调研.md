## 0. 三个颠覆之前判断的核心发现

### 发现 1：个人主体的红线比想象的更硬

之前我以为"个人主体能做的类目有限"，但具体边界可以现场核实。调研证实：

- **AI 类目（深度合成/AI 问答/AI 创作/AI 绘画/AI 换脸）对个人 100% 关闭**，企业也要算法备案+标注"AI 生成"。来源：腾讯新闻 + 微信类目表双重确认 ✅
- **社交/资讯/笔记/阅读 类目对个人全部关闭** ✅
- 个人**唯一安全区是「工具」大类下的三级类目**（记账/日历/天气/办公/图片处理/计算器/报价/信息查询/预约/健康管理/备忘录等）

**这意味着**：之前 v1/v2 推荐里涉及"笔记分享""读书打卡社交""收藏社区"的方向——**全部会被卡审核**。沽酒家（古诗词小程序）就是因为做了图文笔记分享功能被卡死，作者最终放弃小程序转向 App（✅ 一手教训）。

**正确姿势**：做"**单口工具**"（输入→处理→输出，砍掉一切用户间交互），靠"用户生成图自己发朋友圈"做点对点分享（不是平台 UGC）。这是合规边界内的唯一分享机制。

### 发现 2：AI 路线对个人是死路，但"反 AI 情绪"是真红利

- **AI + 阅读在小程序里，个人基本吃不到**（类目关闭 + 备案门槛）。
- 但出现了一个**真实的群体性情绪趋势**：用户在公开吐槽"降智小视频""快餐式 AI 读书""AI 时代让人失去专注"——这是群体焦虑，不是个别人吐槽。
- **"沉浸式 RSS"**（个人开发者做的反算法阅读器）押注这股情绪，被少数派专题报道，验证了"个人开发者靠反 AI/慢读趋势能拿到真实用户"。✅ 这是最值得抄的范式。

**结论**：在阅读领域，个人开发者的机会不在"AI+"，而在"**反算法/慢/专注/仪式感**"。

### 发现 3：游戏/收藏领域的结构性风口被数据验证

这是最有冲击力的发现，有硬数据支撑：

| 品类 | 2024 市场规模 | 增速 | 用户基数 | 可信度 |
|---|---|---|---|---|
| **谷子经济（二次元周边）** | **1689 亿元** | **同比 +40.63%**，预计 2029 达 3089 亿 | 泛二次元用户 **5.03 亿** | ✅ 多篇文章一致 |
| **集换式卡牌** | **263 亿元** | 过去 5 年**暴增超 110%**，卡游市占 71.1% | 个别卡二手炒到千万级 | ✅ |
| 泡泡玛特（潮玩） | 2025 营收 371.2 亿 | +184.7%，净利 +284.5% | Labubu 出圈 | ✅ |

**关键缺口**：搜"手办收藏管理 App"返回的具体工具名为**零**，只有电商模板源码——**国内垂直"藏品管理+展示"工具是空白或极度分散** ✅。海外对标是 MyFigureCollection（手办数据库），国内无对标。

## 1. 需求图谱汇总

### 阅读/文字类

| 状态 | 方向 |
|---|---|
| 🔴 已饱和（红海，别碰） | 读书打卡、书摘/摘抄、泛读书笔记（CSDN 源码满天飞，同质化） |
| 🟢 有真实需求 | 听文章/TTS、OCR 文字提取、双语对照按句对齐、净化版阅读器 |
| 🟡 有需求缺好产品 | 古诗词/古文工具（必须砍 UGC）、书法集字、公众号文章结构化整理 |
| 🆕 新兴趋势 | 反 AI/慢读/仪式感（沉浸式 RSS 验证可行）；AI 玩法个人吃不到 |

### 游戏/收藏类

```
玩家/收藏家 ──→ 在小程序里 ─┬── 查（攻略/价格/识别）── 已被攻略站/闲鱼占据，别做
                          ├── 记（库/通关/入库）── 蓝海，国内缺好工具 ✅
                          ├── 晒（生成海报/年度报告）── 蓝海 + 自传播 ✅✅
                          └── 找同好（社区）── 个人主体做不了 ❌
```

**个人开发者在游戏/收藏领域，唯一同时满足"有人用 + 个人能做 + vibecoding 友好"的切口是「记录 + 晒」**。

## 3. "晒"机制为什么在小程序生态特别有效（硬证据）

搜狗微信抓到的原文证据：
- 「地图形象直观，其他用户很容易通过二维码加入晒图大军，因此形成了**病毒式传播**」
- 「手机端『收款小成就』看年度总结，**朋友圈晒图必备**」
- 麦当劳限定品：「买到的网友纷纷**晒图庆贺**」

**关键认知**：**不能做 UGC 信息流 ≠ 不能做社交传播**。做"用户自己生成一张精美图 → 自己发朋友圈"——这是点对点分享，不是平台 UGC，类目上落在「工具」即可，安全。小程序海报长按识别二维码回流的闭环是原生支持的，这是小程序相对 App 的独特优势。

## 4. 个人主体可切入的具体机会（按推荐度）

### 阅读/文字领域（按性价比）
1. **双语对照阅读器**（按句对齐）——考研党/原版党刚需，付费意愿高
2. **公众号文章听读（垂直版）**——专做某类长文
3. **古诗词/书法单口工具**（**砍掉一切 UGC**）——沽酒家教训已证明必须删分享
4. **OCR 超细分场景**（手写/票据/试卷）
5. **仪式感/专注阅读器**——押注反算法情绪

### 游戏/收藏领域（按推荐度）
1. **⭐ 谷子/卡牌收藏目录 + 库存海报**——贴 1689 亿/+40% 风口，国内空白，自传播强
2. **⭐ 中国版 Backloggd（游戏通关护照）**——纯粹游戏日志 + 通关护照海报
3. **年度报告海报生成器（垂直题材）**——最轻量，季节性投放
4. 植物/印章/手帐打卡——变现密度低，练手可以

## 5. 验证需求真伪的方法论

### 怎么读需求信号
- **抱怨句式比"好用"更能暴露缺口**：搜"难用""求推荐""有没有……可以""为什么不能……"
- **收藏 + 私信追问 + 付费意愿**才是强信号；点赞是廉价信号
- **朋友测试不可信**（给面子 + 朋友≠目标用户）

### 在哪搜真实抱怨
| 平台 | 搜什么 |
|---|---|
| 小红书 | "小程序 推荐""读书工具 难用""求推荐 …"——看评论区 |
| 知乎 | "有哪些好用的…小程序""……怎么解决"——看高赞痛点 |
| 贴吧 | 对应兴趣吧（书法吧、考研吧、古诗词吧、谷子吧） |
| 少数派/什么值得买 | 站内搜"小程序"——工具党聚集地 |
| 微信搜一搜 | 直接搜品类词，看评价区骂什么 |

### 陌生人验证三板斧
1. 做最小可玩版发到陌生人多的平台（小红书/即刻/少数派/V2EX），看自然互动率
2. 看是否有人主动问"收费吗""什么时候上线"
3. 搜痛点关键词，如果已有陌生人在公开抱怨、且无满意产品——真需求
