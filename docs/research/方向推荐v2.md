## 0. 这次的设计原则

v1 失败在"实用工具思维"。这次按你的画像换成"**作品思维**"：

- **贴你的领域**：阅读 / 文字 / 游戏 / 收藏 —— 这样做出来才像"你的作品"，而不是任何人的练手项目
- **有视觉记忆点**：每个方向都要有一个"一眼惊艳"的视觉元素（不是表单和列表）
- **有分享触发点**：内置生成可分享图/卡的机制，让作品自带传播
- **个人主体合规**：全部落在"工具-信息查询/备忘录/办公"等可做类目，避开 AI 生成、社交平台、UGC 传播等红线

⚠️ **关于"社交"的合规边界**（重要）：
个人主体**不能做"社交"类目**（社区论坛、UGC 信息流）。所以"社交/分享"在这里的正确实现方式是：**生成一张图/一个结果让用户主动保存去微信/朋友圈分享**（像网易云年度测试、各种人格测试那样），而不是做"用户在里面互相关注/评论"的平台。下面所有方向的"社交"都是前者。

## 1. ⭐ 阅读人格 / 读书光谱卡

**一句话**：答几道关于阅读偏好的题，生成一张你专属的"读书人格卡"（像 MBTI 但只关于阅读），可分享。

- **类目**：工具 - 信息查询（个人可做 ✓；本质是测试/查询工具，非社交平台）
- **核心功能**（4 个）：
  1. 测试流：12-16 道题，关于阅读口味（题材、节奏、长度、译本偏好等）
  2. **人格卡生成**：算出你的"阅读人格"（如"深夜侦探小说家""午后散文漫游者"等命名 + 描述），用 canvas 绘制成一张精美卡片
  3. 卡片保存到相册 / 分享
  4. （可选）历史结果对比、再测一次
- **视觉记忆点**：人格卡本身——暗色底 + 抽象插画 + 优雅排版，是"作品的脸"
- **分享触发点**：卡片天生为分享而生（人格测试类的小程序爆火都靠这个机制）
- **vibecoding 友好**：★★★★★
  - 测试流就是"题库数组 + 当前题号 state + 答案累加"，AI 写得最稳的状态机
  - 人格计算是简单的分数映射（IF-THEN），AI 不容易错
  - 卡片生成用 canvas 2D API，官方文档明确可喂给 AI
  - **几乎不用平台 API**：保存图片到相册、分享，就这两个
  - 不需要后端、不需要用户系统、不需要 UGC
- **展示亮点**：你做出后，自己测一遍发朋友圈就是一次作品展示；阅读人格的命名/插画是你的创作表达
- **周期**：4-6 天

## 2. ⭐ 收藏柜 / 我的展柜（藏品展示）

**一句话**：把你收藏的东西（胶片相机、手办、黑胶、耳机、植物、什么都行）做成一个"虚拟展柜"，每件藏品有卡片、故事、旋转视图，可分享整个展柜。

- **类目**：工具 - 信息查询 或 备忘录（个人可做 ✓；纯个人藏品记录，不涉及交易就是合规的"信息展示"）
- **核心功能**（5 个）：
  1. 添加藏品：照片（多张）、名称、入手日期、故事/备注、标签
  2. **展柜视图**：所有藏品以卡片墙/网格展示，带入场动画
  3. 藏品详情：大图、故事、入手时间线
  4. 整个展柜生成一张"我的收藏海报"分享
  5. 简单统计：共 X 件、最贵的品类、入手时长
- **视觉记忆点**：展柜的卡片墙 + 入场动画；详情页的大图沉浸感
- **分享触发点**：生成"我的收藏海报"，让别人一眼看到你的品味
- **vibecoding 友好**：★★★★
  - 数据驱动（`collection[]` 渲染卡片墙），AI 最擅长
  - 多图上传用 `wx.chooseMedia`，是标准 API
  - 海报生成用 canvas，和 #1 同套路
  - 没有实时、没有支付、没有复杂交互
- **展示亮点**：贴你"收藏兴趣"的领域；展柜本身就是"你的博物馆"，非常有个人印记
- **周期**：5-7 天
- **变体**：可以做成"读书角"（书架展示）、"观影墙"（电影海报墙）、"唱片架"——选你最想展示的那个领域

## 3. 文字游戏 / 诗意生成器（模板类，非 AI）

**一句话**：基于固定模板和你的输入，生成一首"伪诗"/一段有设计感的文字（如"冰箱诗""便当盒诗"），可排版成海报分享。

- **类目**：工具 - 信息查询 或 办公（个人可做 ✓；**关键是不能调大模型 API** —— 那会触发深度合成类目。用纯模板拼装，合规）
- **核心机制**：用户填几个词（名词/动词/心情），套进精心设计的模板（你预先写好几十个），输出一段排版优美的文字 + 海报
- **核心功能**（4 个）：
  1. 输入引导：填空式（"一个名词""一个颜色""今天的心情"）
  2. 模板随机/选择：套进预设模板，生成文字
  3. **海报生成**：文字 + 背景图 + 排版，canvas 生成可保存
  4. 历史作品库
- **视觉记忆点**：海报的排版美感（字体、留白、背景纹理）
- **分享触发点**：海报天生为分享而生
- **vibecoding 友好**：★★★★★
  - 纯前端模板字符串拼接，AI 写字符串最稳
  - 海报 canvas 同套路
  - 完全没有平台 API 难点
- **展示亮点**：贴你"文字/阅读"领域；模板设计是你的创作；做出来有文艺感
- **⚠️ 合规红线**：**不能用 AI 模型生成文字**。必须是固定模板的填词替换（类似"疯狂填词"游戏）。这样属于"工具"而非"深度合成"。这一点务必遵守，否则个人主体上线会被拒
- **周期**：3-5 天

## 4. 游戏成就卡 / 通关护照

**一句话**：记录你通关/玩过的游戏，每款打"通关护照章"，集齐成一本游戏护照，可生成"我的游戏年度海报"。

- **类目**：工具 - 信息查询（个人可做 ✓；纯个人记录）
- **核心功能**（4-5 个）：
  1. 添加游戏：封面、标题、通关日期、评分、一句话感想
  2. **护照视图**：每款游戏一个"印章"，按时间排列像通关护照
  3. 详情页：大封面 + 感想 + 通关时长
  4. **年度海报**：今年通关 X 款、最爱类型、评分分布 → 生成可分享海报
  5. （可选）愿望清单
- **视觉记忆点**：护照印章的设计（复古、有质感）、年度海报的数据可视化
- **分享触发点**：年度海报（和 v1 的 #2 同机制，但贴游戏领域更有你的印记）
- **vibecoding 友好**：★★★★
  - 数据驱动 + canvas 海报，套路成熟
  - 接 IGDB / 维基百科 API 查游戏信息（可选，手动输入也行）
- **展示亮点**：贴你"游戏/收藏"领域；"通关护照"概念有巧思（不是普通列表）
- **周期**：5-7 天

## 我的推荐

**首推 #1 阅读人格卡** 或 **#2 收藏柜** —— 二选一：

- **#1** 更"轻"、更快出活（4-6 天），成品是一张精致的卡片，分享性强，视觉记忆点集中在一个"人格卡"上，适合做"第一件作品"
- **#2** 更"重"、更有持续使用价值（5-7 天），你会一直往里加东西，最后变成"你的数字博物馆"，作品感更厚重

**如果只能做一个、求最快出活且有作品感** → **#1 阅读人格卡**
**如果想要一件能长期沉淀、和你收藏热情深度绑定** → **#2 收藏柜**
